# Guías

Guías paso a paso para replicar experimentos de arte digital y simulación: lo que ya funcionó, explicado para que cualquiera de la clase lo pueda repetir.

Cada guía tiene dos versiones: una página web (más cómoda, con capturas ampliables y código para copiar) y el texto en Markdown aquí en GitHub.

## Houdini

| Guía | Página web | Texto |
|---|---|---|
| **Tornado de partículas**: un embudo con Vortex Force, ruido y render con Karma (Houdini 22) | [Abrir](https://venttisca.github.io/Guias/tornado-houdini/) | [README](tornado-houdini/README.md) |
